# Content
Topic: Soccer technology

## Overview/Introduction/Context
* In soccer to maintain a fair game refrees use game/player technology.
* This technology can prevent bad calls and missed fouls 

## Part A: existing technology

##### Software
* Smart ball system/Goal-line technology
  * The smart ball system is a software created to track the balls exact position in real time
  * Sense if players made contact with the ball
  * Can help make better on field decisions
  * Can help see if the ball went past the goal line in hard decisions
